# 移动与传感器网络课程讲义

2026-10-19 版本；依据2026-10-08至2026-10-16的19段已提供课程记录与配套课件。

## 交付

- 65页中文教科书式讲义，32幅原创TikZ示意图，公式由LaTeX生成
- PDF通过对话附件交付；此目录保存可重建文本源码及材料定位
- 首次术语中英文并列；按授课顺序组织
- 考试重点：Wi-Fi接入数值题30分、传感器异步接入数值题30分、课堂理论问答2×20分。DCF/EDCA吞吐量比较另有教师明确提醒可能考查

## 编译

安装TeX Live（含XeLaTeX、TikZ、fontspec、amsmath、booktabs、fancyhdr、hyperref）与Noto CJK字体。
当前字体路径为Linux的 `/usr/share/fonts/opentype/noto/`。其他系统可将主文件内字体路径改为本机路径，或改用已安装的中文字体名称。
在源码目录运行 `bash build.sh`；输出 `build/handbook.pdf`。连续运行两遍用于目录和交叉引用。

## 内容范围与边界

正文为教学性整理，不是原始录音逐字稿，也不声称包含尚未提供的后续课次。完整教材、录音、PPT二进制和第三方图像没有收入恢复包。
四个source-map文件记录日期、时间与课件定位。原课堂数值题、依据明确中间量整理的题目及补充例题分别标明。
例二的部分参数没有完整原题佐证；隐藏节点题使用课程给出的中间时隙数，不把不完整材料伪装成完整题设。IEEE 802.15.4中的简化SIFS/收发切换模型按课堂用途标注，补充例题数值不是标准默认值。

## 校验

见manifest.json和SHA256SUMS.txt。PDF哈希指本地编译出的PDF；附件平台可能加入来源元数据而改变字节哈希，不能据此误判正文改变。
