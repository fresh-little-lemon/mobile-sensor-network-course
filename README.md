# Mobile Sensor Network — 课程转写校订

本私有仓库专门保存《移动与传感器网络》课程的文字转写修订内容。

## 当前状态

2026-10-17：仓库初始化与写入测试。课程录音的本地小模型转写、原文对照和校订正在进行，尚未完成全量交付。

## 内容范围

- 飞书原始文字记录，作为不改动的对照来源
- 根据本地 ASR、原文和上下文综合校订的 Markdown 正文
- 独立的修订 diff 与修订说明，区分内容修正和断句、标点、大小写修正
- 校订范围、音频时间定位和仍待核实的内容

先前制作的讲义和 slides 不纳入本仓库。

## 校订原则

1. 保留课堂真实口语，包括重复、自我纠正及非规范语法，不将逐字记录改写为教科书。
2. 重点核查片段结尾遗漏、跨片段句子衔接、异常分句和句首大小写。
3. 原文与小模型均不是绝对真值；综合前后文和课程术语判断，必要时重新识别对应音频区间。
4. 无法确认的内容明确标注。语境推定与音频识别依据分开记录，不虚构缺失语句。
5. 保存可追溯的版本和差异；只有经过通读校订的内容才标为已完成。

## 计划目录

- `originals/`：飞书原始转写
- `revised/`：修订版正文
- `diffs/`：修订差异与说明
- `manifest.json`：覆盖范围与处理状态

以上为计划结构，当前首次提交仅包含本 README。
