## Method and limitations

- Two English controls (00:00–00:15 and 00:20–00:35) and eight 15-second anomaly windows (00:51:20–00:53:20), each run with independent OpenAI Whisper small and Qwen short-window sensitivity check. The second Qwen run is not an independent architecture.
- Models run sequentially, CPU two threads, 16 kHz mono float32 decoded input without normalization, automatic language detection, greedy generation capped at 96 new tokens. Source/model hashes and complete raw outputs are preserved. The cap is computational control, not evidence of quality.
- Original 1024-token long-window and split-check failures remain unchanged in raw_asr. Do not treat model-only Chinese conversation, numbers, isolated words or long loops as verified speech.
- No-speech diagnostic uses the correct Whisper <|nocaptions|> token. Neither that score, RMS nor empty output establishes silence. Clear-English success does not validate difficult-window wording.

## Findings

- Of ten windows, Whisper has four possible generation-cap outputs and Qwen has one capped output; all are in the eight-window anomaly region. Shortening the window does not reliably recover its words.

- In the anomaly interval Qwen produces Chinese guesses including school-related wording, while Whisper produces unrelated syllabic loops, Khmer-script output, or unrelated Russian/English guesses. No new private-looking detail or long repetition is independently confirmed; neither model output is promoted to speech.
