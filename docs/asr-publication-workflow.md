# ASR先提交、再校订

每份录音的自动转写完成后，先提交完整原始ASR输出、模型与运行配置、音频摘要、覆盖和异常记录。随后从GitHub读取核对内容与哈希，确认保存成功，再继续校订与双语翻译。原始录音不放入公开代码仓库。

运行中的已完成片段也可以先按检查点提交，但必须标为进行中，不能记为整份完成。校订、原始文字、独立diff、双语稿分别保存。提交失败时保留本地并建立独立持久备份，不宣称已经发布。
